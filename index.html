📡 One-Time Setup Required

This app reads NSE data from Google Drive. A free API Key is needed to list files. This is a one-time setup — the key is saved on your device.

  1. Go to Google Cloud Console → Credentials
  2. Click + Create Credentials → API Key
  3. Click Edit API Key → under "API restrictions" → select Restrict key → choose Google Drive API
  4. Under "Application restrictions" → leave as None (or select Websites and add https://capavankumarjagiasi.github.io/*)
  5. Click Save → copy the key (starts with AIza…) and paste below
